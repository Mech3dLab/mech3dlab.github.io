MECH3DLAB GITHUB PAGES

Upload index.html, about.html, products.html and styles.css to the root of the mech3dlab.github.io repository. Replace the current files and commit to main.

To add an image, create assets in GitHub and upload a JPG. Replace a placeholder div with:
<div class="card-media"><img src="assets/image-name.jpg" alt="Product name"></div>
